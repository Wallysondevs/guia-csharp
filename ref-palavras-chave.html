C# Palavras-chave

Palavras-chave são as palavras que o próprio C# usa: if, class, int, return… Esta página lista todas, cada uma com o que faz, um exemplo curto e a aula que ensina. Elas são de dois tipos: as reservadas, que nunca podem ser nome de variável, e as contextuais, que só são especiais em certos lugares do código.

As duas listas foram conferidas no compilador do laboratório (o dotnet 10.0.112, C# 14): cada palavra foi usada como nome de variável (int palavra = 1;), e as reservadas são exatamente as que deram erro.

São 77, todas em minúsculas. Nenhuma pode ser nome de variável, método ou classe (a não ser com @ na frente, veja Quando dá errado):

Como o C# diferencia maiúsculas de minúsculas, Class, INT e If não são palavras-chave. Compilam, mas confundem quem lê: não use.

Palavras-chave contextuais

Estas só têm significado especial em certos lugares. Fora deles, são nomes comuns: string var = "ok"; e int record = 14; compilam. Por isso o C# pôde ganhar palavras novas (como record, em 2020, e field, em 2025) sem quebrar programas antigos que já usavam esses nomes. Mesmo assim, evite usá-las como nome: confunde quem lê.

args não é palavra-chave

Nas instruções de nível superior, args é só o nome do parâmetro que recebe a linha de comando (aula Argumentos da Linha de Comando). O mesmo vale para Main, Console e List: são nomes do .NET, não da linguagem.

Duas contextuais em ação: field C# 14 poupa declarar o campo de uma propriedade que limpa o texto, e extension C# 14 acrescenta um método ao string:

Produto p = new() { Nome = "  caderno  " };
Console.WriteLine($"[{p.Nome}]");
Console.WriteLine("lojinha".Gritar());

class Produto
{
    public string Nome
    {
        get => field;
        set => field = value.Trim();
    } = "";
}

static class Extensoes
{
    extension(string s)
    {
        public string Gritar() => s.ToUpper() + "!";
    }
}

Quando dá errado

CS1001: uma palavra reservada como nome de variável

A Ana calculava a área de um triângulo e chamou a variável de base, como na aula de matemática:

double base = 4;
double altura = 3;
Console.WriteLine($"Área: {base * altura / 2}");

$ dotnet run triangulo.cs
/home/ana/cs/kw/triangulo.cs(1,8): error CS1001: Identificador esperado
/home/ana/cs/kw/triangulo.cs(1,8): error CS1003: Erro de sintaxe, "," esperado

Ocorreu uma falha no build. Corrija os erros de build e execute novamente.

O que significa: "identificador esperado" (em inglês, Identifier expected): depois de double, o compilador esperava um nome, e encontrou base, que é uma palavra da linguagem (a classe mãe, aula base). A segunda mensagem é consequência da primeira. Com outras palavras, a cascata pode ser bem maior: int class = 5; deu 13 erros no laboratório, todos por causa da mesma palavra.

Como consertar: o melhor é trocar o nome: baseTriangulo, lado. Se o nome tem mesmo de ser aquele (por exemplo, um campo de um JSON chamado "class"), ponha @ na frente: @base, @class. O @ diz "isto é um nome, não a palavra-chave", e não faz parte do nome.

int @class = 5;
string var = "contextual";
int record = 14;
Console.WriteLine($"{@class} {var} {record}");

$ dotnet run arroba.cs
5 contextual 14

Experimente

Missão: este é o programa do triângulo, com o erro CS1001. Conserte do jeito que preferir (trocando o nome da variável nas duas linhas, ou com @) para a saída ser Área: 6.

double base = 4;
double altura = 3;
Console.WriteLine($"Área: {base * altura / 2}");

double lado = 4;
double altura = 3;
Console.WriteLine($"Área: {lado * altura / 2}");

Resumo

  • O C# 14 tem 77 palavras reservadas, todas em minúsculas. Nenhuma pode ser nome, a não ser com @ (@class).
  • Usar uma reservada como nome dá CS1001: Identificador esperado, às vezes com uma cascata de outros erros na mesma linha.
  • As contextuais (var, record, async, field…) só são especiais em certos lugares; fora deles, são nomes comuns. É assim que a linguagem ganha palavras novas sem quebrar código antigo.
  • Os tipos (int, string, bool…) são apelidos de tipos do .NET: int = System.Int32.
  • args, Main e Console não são palavras-chave.
