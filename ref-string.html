Antes de tudo: a string não muda

Nenhum método de string muda o texto original. ToUpper, Trim, Replace e todos os outros devolvem uma string nova. Se você não guardar o resultado, ele se perde:

string nome = "ana";
nome.ToUpper();
Console.WriteLine(nome);
nome = nome.ToUpper();
Console.WriteLine(nome);

$ dotnet run imut.cs
ana
ANA

A linha 2 criou "ANA" e jogou fora; só a linha 4, que guarda o resultado em nome, mudou o que a variável mostra. Essa regra (a string é imutável) é o motivo de existir o StringBuilder, no fim desta página.

StringBuilder

O StringBuilder (de System.Text) é um texto que muda: cada Append acrescenta no mesmo objeto, sem criar uma string nova. É o certo para montar um texto em muitos pedaços, num laço.

// sb.cs — StringBuilder
using System.Text;

StringBuilder sb = new();
sb.Append("Lista de compras");
sb.AppendLine(":");
foreach (string item in new[] { "arroz", "feijão", "café" })
{
    sb.Append("- ").AppendLine(item);
}
sb.AppendLine($"Total: {3} itens");
Console.Write(sb.ToString());
Console.WriteLine($"Length: {sb.Length}");

sb.Clear();
sb.Append("Ana");
sb.Insert(0, "Sra. ");
sb.Append('!', 3);
sb.Replace("Ana", "Ana Maria");
Console.WriteLine(sb);
sb.Remove(0, 5);
Console.WriteLine(sb);
sb[0] = 'a';
Console.WriteLine($"{sb} {sb.Length} {sb[0]}");

Resumo

  • A string é imutável: todo método devolve uma string nova. Guarde o resultado.
  • Length e [i] (do 0); pedaços com Substring ou [a..b]; posições com IndexOf (-1 = não achou).
  • Trim, ToUpper, ToLower, Replace, PadLeft, Insert, Remove transformam; Contains, StartsWith, EndsWith perguntam.
  • Split corta (com RemoveEmptyEntries e TrimEntries); string.Join junta.
  • Para validar entrada, string.IsNullOrWhiteSpace. Para comparar sem ligar para maiúsculas, StringComparison.OrdinalIgnoreCase.
  • Muitos pedaços num laço: StringBuilder com Append/AppendLine e, no fim, ToString().
