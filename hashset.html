C# HashSet<T>

Às vezes você não quer uma lista, quer um conjunto: as figurinhas que a Ana já tem, os nomes de quem confirmou presença, as palavras que já apareceram num texto. Num conjunto, cada coisa aparece uma vez só, e a pergunta mais importante é "isto está aqui?". O HashSet<T> responde essa pergunta num instante, mesmo com milhões de itens, e ainda faz as contas de conjuntos da escola: união, interseção e diferença.

Você vai aprender
  • O que é um conjunto e como criar um HashSet<T>.
  • Add (e o bool que ele devolve), Contains, Remove e Count.
  • Tirar os repetidos de uma lista em uma linha.
  • Por que a ordem não é garantida, e o SortedSet<T>.
  • União, interseção e diferença: UnionWith, IntersectWith, ExceptWith, SymmetricExceptWith.
  • Perguntas de conjunto: IsSubsetOf, Overlaps, SetEquals.
  • Conjuntos de objetos seus: por que uma class deixa entrar "repetidos" e um record não.
  • Os erros reais: CS0021 (o conjunto não tem posições) e a InvalidOperationException do foreach.

Todos os programas desta aula rodaram com o .NET 10 na máquina da Ana (usuária ana, computador notebook), na pasta ~/cs, com dotnet run arquivo.cs. Você pode repetir cada um no editor do guia.

A ideia: um álbum de figurinhas

A Ana coleciona figurinhas. No álbum, cada figurinha tem um lugar só: colar a figurinha 7 de novo não cria uma segunda 7, ela vai para o monte de repetidas. E, quando um amigo oferece uma figurinha, a primeira pergunta é: "eu já tenho essa?".

Um HashSet<T> ("conjunto por hash") é esse álbum:

  • Não aceita repetidos. Tentar acrescentar um item que já está lá não faz nada (e ele avisa que não fez).
  • Não tem posições. Não existe "a figurinha da posição 0". Existe só "tem" ou "não tem".
  • Responde "tem?" muito rápido. Numa List, o Contains olha item por item; num HashSet, ele vai direto ao lugar certo, como o Dictionary faz com as chaves.

O T em HashSet<T> é o tipo dos itens, escolhido por você: HashSet<int> guarda números; HashSet<string>, textos (veja Generics).

Como o Dictionary, o conjunto não mostra o conteúdo: aparece só o nome do tipo. Para ver os itens, use foreach ou string.Join.

O bool do Add trabalha para você

Como o Add já diz se o item é novo, você não precisa de um Contains antes. Este laço acha as figurinhas repetidas de um pacote numa passada só:

int[] pacote = [5, 18, 5, 40, 18, 5];
var album = new HashSet<int>();

foreach (int fig in pacote)
{
    if (!album.Add(fig))
        Console.WriteLine($"Repetida: {fig}");
}
Console.WriteLine($"Coladas: {album.Count}");

$ dotnet run pacote.cs
Repetida: 5
Repetida: 18
Repetida: 5
Coladas: 3

Leia if (!album.Add(fig)) como "se não deu para colar". O ! é o "não" de Operadores Lógicos. O Add sempre tenta colar; quando devolve false, a figurinha era repetida.

Criar já com itens

Dá para criar o conjunto com itens entre chaves (o inicializador) ou a partir de outra coleção. Repetidos são ignorados nas duas formas:

var cores = new HashSet<string> { "azul", "verde", "azul" };
int[] numeros = [3, 1, 3, 2];
var semRepetir = new HashSet<int>(numeros);
HashSet<char> vogais = ['a', 'e', 'i', 'o', 'u'];

A última linha usa a expressão de coleção [ … ] C# 12, que também funciona com HashSet quando o tipo está escrito à esquerda.

2. Tirar os repetidos de uma lista

A Ana anotou quem confirmou presença na festa, mas algumas pessoas confirmaram duas vezes. Quantas pessoas vêm de verdade?

string[] convidados = ["Ana", "Bruno", "Ana", "Carla", "Bruno", "Ana"];

var semRepetir = new HashSet<string>(convidados);

Console.WriteLine($"Nomes na lista: {convidados.Length}");
Console.WriteLine($"Pessoas diferentes: {semRepetir.Count}");

foreach (string nome in semRepetir)
{
    Console.WriteLine(nome);
}

$ dotnet run repetidos.cs

Pessoas diferentes: 3
Ana
Bruno
Carla

A linha new HashSet<string>(convidados) passa todos os nomes do array para o conjunto, e os repetidos simplesmente não entram. O foreach percorre o conjunto como percorreria uma lista.

A ordem de um HashSet

Os convidados saíram na ordem em que foram anotados, mas não conte com isso. O HashSet não promete nenhuma ordem: ele guarda cada item no lugar que o hash code do item indica (uma "impressão digital" numérica; veja A Classe object), e, quando um item sai, o próximo que entra pode ocupar o lugar vago:

var cores = new HashSet<string> { "azul", "verde", "vermelho", "amarelo" };
Console.WriteLine(string.Join(", ", cores));

cores.Remove("verde");
cores.Add("roxo");
Console.WriteLine(string.Join(", ", cores));

var ordenado = new SortedSet<string>(cores);
Console.WriteLine(string.Join(", ", ordenado));

$ dotnet run ordem.cs
azul, verde, vermelho, amarelo
azul, roxo, vermelho, amarelo      « o roxo entrou por último, mas ficou no lugar do verde
amarelo, azul, roxo, vermelho      « SortedSet: sempre em ordem
Nunca dependa da ordem de um HashSet

Se a ordem importa, use um SortedSet<T> (que mantém os itens sempre ordenados e tem os mesmos métodos Add, Contains, Remove…) ou ordene na hora de mostrar, com o Order() do LINQ: string.Join(", ", cores.Order()). O SortedSet é um pouco mais lento que o HashSet; use-o só quando precisar da ordem.

3. Operações de conjunto

Lembra dos diagramas de Venn da escola, com dois círculos que se cruzam? O HashSet faz essas contas. A Ana e o Bruno escolheram matérias para a monitoria:

  Ana:    Matemática  Física  Química
  Bruno:              Física  Química  História
var ana = new HashSet<string> { "Matemática", "Física", "Química" };
var bruno = new HashSet<string> { "Física", "História", "Química" };

var juntas = new HashSet<string>(ana);
juntas.UnionWith(bruno);
Console.WriteLine($"União: {string.Join(", ", juntas.Order())}");

var comum = new HashSet<string>(ana);
comum.IntersectWith(bruno);
Console.WriteLine($"Interseção: {string.Join(", ", comum.Order())}");

var soAna = new HashSet<string>(ana);
soAna.ExceptWith(bruno);
Console.WriteLine($"Só a Ana: {string.Join(", ", soAna.Order())}");

var soUm = new HashSet<string>(ana);
soUm.SymmetricExceptWith(bruno);
Console.WriteLine($"Só um dos dois: {string.Join(", ", soUm.Order())}");

Console.WriteLine($"ana continua com {ana.Count}");

$ dotnet run operacoes.cs
União: Física, História, Matemática, Química
Interseção: Física, Química
Só a Ana: Matemática
Só um dos dois: História, Matemática
ana continua com 3
MétodoTraduçãoFica com…Na escola
a.UnionWith(b)"unir com"tudo o que está em a ou em bA ∪ B
a.IntersectWith(b)"cruzar com"só o que está em a e em bA ∩ B
a.ExceptWith(b)"tirar o que tem em"o que está em a e não está em bA − B
a.SymmetricExceptWith(b)"diferença simétrica"o que está em um só dos doisA Δ B
Esses métodos mudam o próprio conjunto

a.UnionWith(b) não devolve um conjunto novo: ele altera o a (e devolve void, nada). Por isso o programa copia a Ana antes de cada conta (new HashSet<string>(ana)), e no fim o conjunto ana continua com 3 matérias. Se você fizer ana.IntersectWith(bruno) direto, perde a Matemática da Ana.

4. Maiúsculas e minúsculas

Para o HashSet<string>, "CSharp" e "csharp" são itens diferentes. Como no Dictionary, um comparador na criação muda isso:

var tags = new HashSet<string>(StringComparer.OrdinalIgnoreCase) { "CSharp", "csharp", "CSHARP", "dotnet" };
Console.WriteLine(tags.Count);
Console.WriteLine(tags.Contains("DotNet"));

$ dotnet run caixa.cs
2                « as três formas de "csharp" contaram como uma só

5. Conjuntos de objetos seus: class × record

Para saber se um item "já está lá", o HashSet precisa comparar itens. Com números e textos, ele compara o conteúdo. Com objetos de uma class sua, o padrão é comparar a identidade: dois objetos criados com new são dois objetos diferentes, mesmo com os mesmos dados (veja Valor × Referência).

var pontosClasse = new HashSet<PontoClasse>();
pontosClasse.Add(new PontoClasse { X = 1, Y = 2 });
pontosClasse.Add(new PontoClasse { X = 1, Y = 2 });
Console.WriteLine($"class: {pontosClasse.Count}");

var pontosRecord = new HashSet<PontoRecord>();
pontosRecord.Add(new PontoRecord(1, 2));
pontosRecord.Add(new PontoRecord(1, 2));
Console.WriteLine($"record: {pontosRecord.Count}");

class PontoClasse
{
    public int X { get; set; }
    public int Y { get; set; }
}

record PontoRecord(int X, int Y);

$ dotnet run objetos.cs
class: 2               « dois objetos diferentes, mesmo com X = 1 e Y = 2
record: 1              « o record compara os dados: é o mesmo ponto

Um record já vem com Equals e GetHashCode que comparam os dados, por isso o segundo ponto (1, 2) não entrou. Numa class, você teria de escrever esses dois métodos (aula A Classe object). Regra prática: para guardar objetos "de dados" num HashSet ou usá-los como chave de um Dictionary, prefira record.

6. Mudar o conjunto dentro do foreach

Como no Dictionary, você não pode acrescentar itens no conjunto que o foreach está percorrendo:

var album = new HashSet<int> { 7, 12, 30 };

foreach (int fig in album)
{
    album.Add(fig + 100);
}

$ dotnet run foreach.cs
Unhandled exception. System.InvalidOperationException: Collection was modified; enumeration operation may not execute.
   at System.Collections.Generic.HashSet`1.Enumerator.MoveNext()
   at Program.<Main>$(String[] args) in /home/ana/cs/foreach.cs:line 3
$ echo $?
134

"A coleção foi modificada; o percurso não pode continuar." A linha apontada é a 3, a do foreach: o Add funcionou, mas o foreach percebeu a mudança quando foi buscar o próximo item (MoveNext). Para acrescentar, junte os itens novos em outra coleção e acrescente depois do laço. E, para tirar todos os itens que cumprem uma condição, o HashSet tem um método pronto, o RemoveWhere ("remover onde"):

var album = new HashSet<int> { 7, 12, 30, 41, 50 };
int tirados = album.RemoveWhere(n => n % 2 == 0);
Console.WriteLine($"Tirados: {tirados}");
Console.WriteLine(string.Join(", ", album.Order()));

$ dotnet run removewhere.cs
Tirados: 3
7, 41

O n => n % 2 == 0 é uma lambda: uma minifunção que recebe cada número n e diz se ele deve sair (aqui, os pares: resto 0 na divisão por 2). O RemoveWhere devolve quantos itens tirou.

Qual coleção usar?

Você quer…Use
Itens em ordem, com posição, repetidos permitidosList<T>
Itens sem repetir; perguntar "tem?" rápido; a ordem não importaHashSet<T>
Itens sem repetir, sempre em ordemSortedSet<T>
Ligar cada item a um valor (nome → nota)Dictionary<TKey, TValue>

Quando dá errado

error CS0021: Não é possível aplicar a indexação com [] a uma expressão do tipo "HashSet<int>"

O que significa: você tentou pegar um item pela posição, como numa lista (album[0]). Um conjunto não tem posições. Em inglês: Cannot apply indexing with [] to an expression of type 'HashSet<int>'.

$ dotnet run indice.cs
/home/ana/cs/indice.cs(2,19): error CS0021: Não é possível aplicar a indexação com [] a uma expressão do tipo "HashSet<int>"

Ocorreu uma falha no build. Corrija os erros de build e execute novamente.

Como consertar: pergunte com Contains, percorra com foreach ou, se você precisa mesmo de posições, use uma List<T>.

InvalidOperationException: Collection was modified; enumeration operation may not execute.

O que significa: você acrescentou itens no conjunto enquanto um foreach o percorria.

Como consertar: guarde os itens novos em outra coleção e acrescente depois do laço (por exemplo, com UnionWith). Para tirar itens por uma condição, use RemoveWhere.

O conjunto aceitou dois objetos "iguais"

O que significa: não há mensagem de erro: o Count simplesmente sai maior do que você esperava. Os itens são de uma class sua, que compara identidade, e não os dados (seção 5).

Como consertar: transforme a classe num record, ou escreva Equals e GetHashCode nela.

A ordem mudou e o programa "quebrou"

O que significa: o programa contava com a ordem do HashSet, que não é garantida e muda depois de remoções.

Como consertar: use SortedSet<T> ou ordene ao mostrar (.Order()).

Resumo

  • Um HashSet<T> é um conjunto: sem repetidos, sem posições e com um Contains muito rápido.
  • Add devolve true se o item entrou e false se ele já estava (sem exceção). Remove devolve se tirou.
  • new HashSet<T>(lista) tira os repetidos de uma lista em uma linha.
  • A ordem não é garantida (muda depois de remoções). Para ordem, use SortedSet<T> ou .Order() ao mostrar.
  • UnionWith, IntersectWith, ExceptWith e SymmetricExceptWith mudam o conjunto: copie antes se precisar do original.
  • Objetos de uma class são comparados pela identidade; os de um record, pelos dados.
  • conjunto[0] dá CS0021; acrescentar dentro do foreach dá InvalidOperationException.
