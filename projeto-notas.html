Projeto Boletim de Notas

A Ana dá aula de reforço para uma turma pequena e quer um programa que faça o boletim: ela digita o nome e a nota de cada aluno, e o programa mostra a média da turma, quem tirou a maior e a menor nota, quantos passaram e uma tabela bem alinhada. É o projeto para treinar arrays (muitos valores numa variável só) e records (os dados de um aluno juntos, num tipo só).

Você vai praticar
  • Guardar as notas num array e percorrê-lo com for e foreach.
  • Somar, tirar a média e mostrar com :N1 (Formatar Números).
  • Juntar nome e nota num record Aluno e fazer um array de alunos.
  • Achar o maior, o menor e contar quem passou, num laço só.
  • Validar a entrada num método LerNota.
  • Decidir a situação com uma expressão switch e alinhar a tabela com {nome,-10}.

Versão 1 · As notas num array e a média

Cinco alunos, cinco notas. Daria para criar nota1, nota2… nota5, mas e se a turma tiver 30? Um array guarda todas numa variável só: notas[0] é a primeira, notas[4] a quinta. E um for passa por todas, sem repetir código.

Versão 2 · Nome e nota juntos: um array de records

Notas sem nome não servem para um boletim. Daria para ter dois arrays, um de nomes e um de notas, e cuidar para a posição 2 de um combinar com a posição 2 do outro. Mais simples: um tipo novo, Aluno, que guarda o nome e a nota de uma pessoa. Em C#, a forma mais curta de criar um tipo assim é um record.

const int Quantidade = 5;

Aluno[] turma = new Aluno[Quantidade];
double soma = 0;

Console.WriteLine("=== Boletim da Turma ===");
for (int i = 0; i < turma.Length; i++)
{
    Console.Write($"Nome do aluno {i + 1}: ");
    string nome = Console.ReadLine()!;
    Console.Write($"Nota de {nome}: ");
    double nota = double.Parse(Console.ReadLine()!);
    turma[i] = new Aluno(nome, nota);
    soma += nota;
}

Console.WriteLine();
foreach (Aluno aluno in turma)
{
    Console.WriteLine($"{aluno.Nome}: {aluno.Nota:N1}");
}
Console.WriteLine($"Média da turma: {soma / turma.Length:N1}");

record Aluno(string Nome, double Nota);

Corrigir uma nota: erro CS8852

A Ana errou a nota do Bruno e tentou trocar direto:

Aluno bruno = new Aluno("Bruno", 7.5);
bruno.Nota = 8;
Console.WriteLine(bruno);

record Aluno(string Nome, double Nota);

$ dotnet run nota.cs
/home/ana/cs/boletim/nota.cs(2,1): error CS8852: A propriedade somente de inicialização ou o indexador 'Aluno.Nota' só pode ser atribuído em um inicializador de objeto, em 'this' ou 'base' em um construtor de instância ou em um acessador 'init'.

Ocorreu uma falha no build. Corrija os erros de build e execute novamente.

O que significa: as propriedades de um record criado assim são init: só recebem valor na criação do objeto (veja readonly e init). Depois, o aluno não muda. Isso é de propósito: um dado que não muda não pode ser estragado por engano em outra parte do programa.

Como consertar: crie um aluno novo, igual ao antigo mas com a nota trocada, com with:

Aluno bruno = new Aluno("Bruno", 7.5);
Aluno corrigido = bruno with { Nota = 8 };
Console.WriteLine(bruno);
Console.WriteLine(corrigido);

record Aluno(string Nome, double Nota);

$ dotnet run nota.cs
Aluno { Nome = Bruno, Nota = 7,5 }
Aluno { Nome = Bruno, Nota = 8 }

De quebra, o record sabe se mostrar: o Console.WriteLine(bruno) escreve o nome do tipo e as propriedades. No boletim, basta guardar o aluno corrigido no lugar do antigo: turma[0] = turma[0] with { Nota = 8 };.

Versão 3 · Maior, menor e aprovados

Agora as estatísticas. Para achar a maior nota, o jeito clássico é: "o maior até agora é o primeiro aluno; para cada um dos outros, se a nota dele for maior, ele passa a ser o maior". Guardamos o aluno inteiro, e não só a nota, porque assim sabemos também o nome. A menor nota é igual, com <. E os aprovados são um contador que sobe quando a nota é pelo menos 6.

const int Quantidade = 5;
const double MediaParaAprovar = 6.0;

Aluno[] turma = new Aluno[Quantidade];
double soma = 0;

Console.WriteLine("=== Boletim da Turma ===");
for (int i = 0; i < turma.Length; i++)
{
    Console.Write($"Nome do aluno {i + 1}: ");
    string nome = Console.ReadLine()!;
    Console.Write($"Nota de {nome}: ");
    double nota = double.Parse(Console.ReadLine()!);
    turma[i] = new Aluno(nome, nota);
    soma += nota;
}

Aluno maior = turma[0];
Aluno menor = turma[0];
int aprovados = 0;
foreach (Aluno aluno in turma)
{
    if (aluno.Nota > maior.Nota)
    {
        maior = aluno;
    }
    if (aluno.Nota < menor.Nota)
    {
        menor = aluno;
    }
    if (aluno.Nota >= MediaParaAprovar)
    {
        aprovados++;
    }
}

Console.WriteLine();
Console.WriteLine($"Média da turma: {soma / turma.Length:N1}");
Console.WriteLine($"Maior nota: {maior.Nota:N1} ({maior.Nome})");
Console.WriteLine($"Menor nota: {menor.Nota:N1} ({menor.Nome})");
Console.WriteLine($"Aprovados: {aprovados} de {turma.Length}");

E se houver empate? E o LINQ?

Com >, o primeiro aluno com a maior nota fica com o título; com >=, ficaria o último. Nenhum dos dois está errado, mas é bom saber qual você escolheu.

Quando você chegar ao LINQ, as mesmas contas cabem em uma linha cada: turma.Average(a => a.Nota), turma.MaxBy(a => a.Nota) e turma.Count(a => a.Nota >= MediaParaAprovar) (veja Agregar). Fazer o laço à mão primeiro ajuda a entender o que o LINQ faz por dentro.

Versão 4 · A tabela alinhada

A versão final tem quatro novidades:

  • A quantidade de alunos é perguntada no começo (de 1 a 30), e o array é criado com o tamanho exato.
  • Um método LerNota pergunta de novo enquanto a nota não for um número de 0 a 10.
  • Um método Situacao, feito com uma expressão switch, devolve "Aprovado", "Recuperação" (de 4 a 5,9) ou "Reprovado".
  • Uma tabela, com as colunas alinhadas pela largura dentro da interpolação.
const int MaxAlunos = 30;
const double MediaParaAprovar = 6.0;

Console.WriteLine("=== Boletim da Turma ===");
Console.Write($"Quantos alunos (1 a {MaxAlunos})? ");
if (!int.TryParse(Console.ReadLine(), out int quantidade) || quantidade < 1 || quantidade > MaxAlunos)
{
    Console.WriteLine("Quantidade inválida.");
    return;
}

Aluno[] turma = new Aluno[quantidade];
for (int i = 0; i < turma.Length; i++)
{
    Console.Write($"Nome do aluno {i + 1}: ");
    string nome = (Console.ReadLine() ?? "").Trim();
    double nota = LerNota(nome);
    turma[i] = new Aluno(nome, nota);
}

double soma = 0;
Aluno maior = turma[0];
Aluno menor = turma[0];
int aprovados = 0;

Console.WriteLine();
Console.WriteLine($"{"Aluno",-10} {"Nota",5}  Situação");
Console.WriteLine("---------- -----  -----------");
foreach (Aluno aluno in turma)
{
    Console.WriteLine($"{aluno.Nome,-10} {aluno.Nota,5:N1}  {Situacao(aluno.Nota)}");
    soma += aluno.Nota;
    if (aluno.Nota > maior.Nota)
    {
        maior = aluno;
    }
    if (aluno.Nota < menor.Nota)
    {
        menor = aluno;
    }
    if (aluno.Nota >= MediaParaAprovar)
    {
        aprovados++;
    }
}
Console.WriteLine("---------- -----  -----------");
Console.WriteLine($"{"Média",-10} {soma / turma.Length,5:N1}");

Console.WriteLine();
Console.WriteLine($"Maior nota: {maior.Nota:N1} ({maior.Nome})");
Console.WriteLine($"Menor nota: {menor.Nota:N1} ({menor.Nome})");
Console.WriteLine($"Aprovados: {aprovados} de {turma.Length}");

static double LerNota(string nome)
{
    while (true)
    {
        Console.Write($"Nota de {nome} (0 a 10): ");
        string? texto = Console.ReadLine();
        if (texto is null)
        {
            Console.WriteLine();
            Console.WriteLine("A entrada acabou antes do fim.");
            Environment.Exit(1);
        }
        if (double.TryParse(texto, out double nota) && nota >= 0 && nota <= 10)
        {
            return nota;
        }
        Console.WriteLine("Nota inválida. Digite um número de 0 a 10.");
    }
}

static string Situacao(double nota) => nota switch
{
    >= MediaParaAprovar => "Aprovado",
    >= 4.0 => "Recuperação",
    _ => "Reprovado"
};

record Aluno(string Nome, double Nota);

Desafios extras

  1. Turma de qualquer tamanho. Troque o array por uma List<Aluno> e leia alunos até a Ana deixar o nome em branco. Não precisa mais perguntar a quantidade.
  2. Duas notas por aluno. Mude o record para Aluno(string Nome, double Prova, double Trabalho) e acrescente uma propriedade Media calculada (veja Records e Propriedades).
  3. Em ordem de nota. Mostre a tabela da maior para a menor nota com Array.Sort ou com o LINQ OrderByDescending (veja A Classe Array e Ordenar).
  4. Com LINQ. Troque o laço da maior, da menor e dos aprovados por MaxBy, MinBy e Count (veja Agregar).
  5. Nomes compridos. Um nome com mais de 10 letras empurra a coluna. Corte com nome[..10] (veja Índices e Intervalos) ou calcule a largura pelo maior nome.

Resumo

  • Um array guarda muitos valores do mesmo tipo; as posições vão de 0 a Length - 1, e o laço é i < array.Length.
  • Passar do fim lança IndexOutOfRangeException com a linha exata; o foreach nunca passa do fim.
  • Um record junta os dados de uma coisa numa linha; as propriedades não mudam depois da criação (with cria uma cópia alterada).
  • Um array de objetos nasce cheio de null: crie-o do tamanho certo ou use List<T>.
  • Maior e menor: comece pelo primeiro e troque quando achar um melhor; guarde o objeto, não só o número.
  • {texto,-10} alinha à esquerda, {numero,5:N1} alinha à direita com formato; no C#, a largura conta letras, e os acentos não desalinham.
