C# Dictionary<TKey, TValue>

Numa List, você encontra as coisas pela posição: o item 0, o item 1, o item 2. Mas muitas vezes você quer encontrar pelo nome: o preço do café, a nota da Ana, o estoque de bananas. Para isso existe o dicionário: Dictionary<TKey, TValue>. Ele liga cada chave a um valor e acha qualquer chave num piscar de olhos, mesmo com um milhão de itens.

Você vai aprender
  • O que são chave e valor, e como criar um Dictionary.
  • Guardar e ler com o indexador [ ], e a diferença para o Add.
  • O que acontece quando a chave não existe: a KeyNotFoundException.
  • Perguntar antes: ContainsKey, TryGetValue, GetValueOrDefault, TryAdd e Remove.
  • Percorrer com foreach, KeyValuePair, Keys e Values.
  • Contar quantas vezes cada palavra aparece.
  • Por que você não deve contar com a ordem e quando usar o SortedDictionary.
  • A InvalidOperationException de mudar o dicionário dentro do foreach.

Todos os programas desta aula rodaram com o .NET 10 na máquina da Ana (usuária ana, computador notebook), na pasta ~/cs, com dotnet run arquivo.cs (veja Rodar com dotnet run). Você pode repetir cada um no editor do guia.

A ideia: um dicionário de papel

Num dicionário de papel, você não procura "a palavra número 3.512": você procura pela palavra e encontra o significado. A palavra é a chave (key); o significado é o valor (value). A tabela de preços da lojinha da Ana é igual:

  chave        valor
  "pão"    →   0,75
  "leite"  →   5,49
  "café"   →  18,90

Duas regras definem um dicionário:

  • Cada chave aparece uma vez só. Não existem dois "pão". Guardar "pão" de novo troca o valor que estava lá.
  • Os valores podem se repetir. O pão e a banana podem custar o mesmo.

No nome Dictionary<TKey, TValue>, os dois tipos entre < > são escolhidos por você: TKey é o tipo da chave e TValue, o do valor. Um Dictionary<string, decimal> é "um dicionário de texto para dinheiro". Essa escolha de tipos entre < > se chama generics e tem aula própria (Generics). O Dictionary mora no namespace System.Collections.Generic, que o .NET já importa sozinho (o using implícito; veja Namespaces e using).

Console.WriteLine(precos);

O Add: guardar só se a chave for nova

Também dá para guardar com o método Add ("acrescentar"). A diferença aparece quando a chave já existe: o indexador troca o valor em silêncio, mas o Add recusa e lança uma exceção.

precos.Add("pão", 0.75m);
precos.Add("leite", 5.49m);
Console.WriteLine($"Produtos: {precos.Count}");

precos.Add("pão", 0.80m);
Console.WriteLine("Esta linha não roda.");

4. Percorrer: foreach, KeyValuePair, Keys e Values

O foreach (aula foreach) passa por todos os pares do dicionário. Cada par é um KeyValuePair<TKey, TValue> ("par chave-valor"), com duas propriedades: Key (a chave) e Value (o valor).

var notas = new Dictionary<string, double>
{
    ["Ana"] = 9.5,
    ["Bruno"] = 7.0,
    ["Carla"] = 8.25,
};

foreach (KeyValuePair<string, double> par in notas)
{
    Console.WriteLine($"{par.Key} tirou {par.Value}");
}

foreach (var (nome, nota) in notas)
{
    Console.WriteLine($"{nome}: {nota}");
}

Console.WriteLine(string.Join(", ", notas.Keys));
Console.WriteLine(notas.Values.Sum() / notas.Count);

foreach (var par in notas)
{
    Console.WriteLine(par);
}

5. Contar coisas: a frequência das palavras

O uso mais clássico de um dicionário: contar quantas vezes cada coisa aparece. A chave é a coisa (a palavra); o valor é quantas vezes ela apareceu.

string frase = "o rato roeu a roupa do rei de roma e o rato fugiu";
var contagem = new Dictionary<string, int>();

foreach (string palavra in frase.Split(' '))
{
    if (contagem.TryGetValue(palavra, out int vezes))
        contagem[palavra] = vezes + 1;
    else
        contagem[palavra] = 1;
}

Console.WriteLine($"Palavras diferentes: {contagem.Count}");
Console.WriteLine($"rato: {contagem["rato"]}");
Console.WriteLine($"o: {contagem["o"]}");
Console.WriteLine($"rei: {contagem["rei"]}");

$ dotnet run contar.cs

rato: 2
o: 2
rei: 1
frase.Split(' ')
Corta a frase em cada espaço e devolve um array com as 13 palavras (veja Métodos de String).
if (contagem.TryGetValue(palavra, out int vezes))
"Essa palavra já foi contada? Se sim, quantas vezes?"

Já existia: guarda a contagem antiga mais 1.

É a primeira vez: começa com 1.

São 13 palavras, mas só 11 diferentes, porque "o" e "rato" aparecem duas vezes. O mesmo laço fica numa linha só com o GetValueOrDefault: "pegue a contagem atual, ou 0 se é a primeira vez, e some 1":

foreach (string palavra in frase.Split(' '))
    contagem[palavra] = contagem.GetValueOrDefault(palavra) + 1;

6. A ordem não é garantida

Por dentro, o Dictionary não guarda os pares numa fila. Ele calcula um número a partir de cada chave (o hash code, uma "impressão digital" numérica; veja A Classe object) e usa esse número para achar a chave depois sem olhar as outras. É por isso que ele é tão rápido.

Num dicionário em que você só acrescenta, o foreach do .NET costuma devolver os pares na ordem em que entraram, como você viu nas notas. Mas isso é um detalhe de como ele foi feito, não uma promessa. Basta uma remoção para a ordem mudar:

var frutas = new Dictionary<string, int>();
frutas["uva"] = 1;
frutas["banana"] = 2;
frutas["maçã"] = 3;
frutas["kiwi"] = 4;
Console.WriteLine(string.Join(", ", frutas.Keys));

frutas.Remove("banana");
frutas["pera"] = 5;
Console.WriteLine(string.Join(", ", frutas.Keys));

var ordenado = new SortedDictionary<string, int>(frutas);
Console.WriteLine(string.Join(", ", ordenado.Keys));

$ dotnet run ordem.cs
uva, banana, maçã, kiwi
uva, pera, maçã, kiwi          « a pera entrou por último, mas ocupou o lugar vago da banana
kiwi, maçã, pera, uva          « SortedDictionary: chaves em ordem alfabética

A pera foi a última a entrar, mas apareceu em segundo: ela reaproveitou o espaço que a banana deixou. Se o seu programa só "funciona" porque o dicionário por acaso mostrou na ordem certa, ele pode quebrar com a primeira remoção.

Nunca dependa da ordem de um Dictionary

Quando a ordem importa, diga isso no código:

  • Ordem alfabética (ou numérica) das chaves: SortedDictionary<TKey, TValue>, que mantém as chaves sempre ordenadas.
  • Uma ordem só na hora de mostrar: ordene as chaves antes, com o Order() do LINQ: foreach (var k in frutas.Keys.Order()).
  • A ordem em que os itens chegaram: guarde-os também numa List.

7. Mudar o dicionário dentro do foreach

Enquanto o foreach anda pelo dicionário, você não pode acrescentar chaves nele. A Ana quis marcar as frutas que acabaram criando uma chave nova "… (encomendar)" no meio do laço:

var estoque = new Dictionary<string, int>
{
    ["maçã"] = 12,
    ["banana"] = 0,
    ["uva"] = 5,
};

foreach (var (fruta, qtd) in estoque)
{
    if (qtd == 0)
        estoque.Add($"{fruta} (encomendar)", 50);
}

$ dotnet run modificar.cs
Unhandled exception. System.InvalidOperationException: Collection was modified; enumeration operation may not execute.
   at System.Collections.Generic.Dictionary`2.Enumerator.MoveNext()
   at Program.<Main>$(String[] args) in /home/ana/cs/modificar.cs:line 8
$ echo $?
134

Em português: "a coleção foi modificada; a operação de enumeração (o percurso) não pode continuar". O Add em si funcionou; quem reclamou foi o foreach, quando tentou ir para o próximo par (MoveNext, "mover para o próximo"). Por isso o rastro aponta a linha 8, a do foreach, e não a do Add. Acrescentar uma chave pode reorganizar o dicionário por dentro, e o percurso perderia o fio.

O conserto é fazer em dois passos: primeiro anote numa lista o que precisa mudar; depois, fora do laço, mude.

var estoque = new Dictionary<string, int>
{
    ["maçã"] = 12,
    ["banana"] = 0,
    ["uva"] = 5,
    ["kiwi"] = 0,
};

var acabaram = new List<string>();
foreach (var (fruta, qtd) in estoque)
{
    if (qtd == 0)
        acabaram.Add(fruta);
}

foreach (string fruta in acabaram)
{
    estoque.Remove(fruta);
    estoque[$"{fruta} (encomendar)"] = 50;
}

Console.WriteLine(string.Join(", ", estoque.Keys.Order()));

$ dotnet run modificar2.cs
banana (encomendar), kiwi (encomendar), maçã, uva

O segundo foreach anda pela lista acabaram, não pelo dicionário, então mexer no dicionário ali é seguro. Como houve remoções, o programa ordena as chaves com Order() antes de mostrar (lembre da seção 6).

E remover dentro do foreach?

Desde o .NET Core 3.0, o Dictionary deixa você remover a chave atual ou trocar o valor de uma chave que já existe durante o foreach, sem exceção. Só acrescentar chaves é proibido. Mesmo assim, o jeito em dois passos funciona em qualquer coleção (a List, por exemplo, reclama também de remoções) e deixa claro o que o código faz.

8. Maiúsculas e minúsculas na chave

Para o dicionário, "Ana" e "ana" são chaves diferentes. Se você quer que ele ignore a caixa das letras, passe um comparador na criação:

var senhas = new Dictionary<string, string>(StringComparer.OrdinalIgnoreCase);
senhas["Ana"] = "girassol";

Console.WriteLine(senhas.ContainsKey("ana"));
Console.WriteLine(senhas["ANA"]);

var normal = new Dictionary<string, string>();
normal["Ana"] = "girassol";
Console.WriteLine(normal.ContainsKey("ana"));

$ dotnet run caixa.cs
True
girassol
False                    « sem o comparador, "ana" não é "Ana"

StringComparer.OrdinalIgnoreCase quer dizer "comparar letra por letra, ignorando maiúsculas e minúsculas". É útil para nomes de usuário, comandos digitados e extensões de arquivo.

Quando dá errado

KeyNotFoundException: The given key 'queijo' was not present in the dictionary.

O que significa: você leu d[chave] com uma chave que não está no dicionário. O programa para com código 134.

Como consertar: confira a grafia da chave (a mensagem mostra exatamente o que foi pedido). Se a chave pode faltar, leia com TryGetValue ou GetValueOrDefault, como na seção 3.

ArgumentException: An item with the same key has already been added. Key: pão

O que significa: um Add (ou um inicializador { "pão", … }) tentou guardar uma chave que já existe.

Como consertar: se trocar o valor é o que você quer, use o indexador: d["pão"] = 0.80m;. Se a chave nova não deve apagar a antiga, use TryAdd e veja o bool que ele devolve. Se a repetição é um erro nos dados, a exceção está certa: conserte os dados.

InvalidOperationException: Collection was modified; enumeration operation may not execute.

O que significa: você acrescentou uma chave enquanto um foreach percorria o mesmo dicionário. O rastro aponta a linha do foreach.

Como consertar: faça em dois passos: anote numa List o que mudar e mude depois do laço (seção 7).

error CS1503: Argumento 1: não é possível converter de "int" para "string"

O que significa: a chave que você passou não é do tipo TKey. Com Dictionary<string, int> estoque, a linha estoque[1] tenta usar um número como chave, como se fosse uma lista:

$ dotnet run tipo.cs
/home/ana/cs/tipo.cs(2,27): error CS1503: Argumento 1: não é possível converter de "int" para "string"

Ocorreu uma falha no build. Corrija os erros de build e execute novamente.

Como consertar: um dicionário não tem posições, só chaves. Use a chave (estoque["maçã"]). Se você precisa "do primeiro item", talvez a coleção certa seja uma List.

string[] vendas = ["banana", "maçã", "banana", "uva", "maçã", "banana"];

var contagem = new Dictionary<string, int>();

foreach (string fruta in vendas)
{
    contagem[fruta] = contagem.GetValueOrDefault(fruta) + 1;
}

foreach (var (fruta, vezes) in contagem)
{
    Console.WriteLine($"{fruta}: {vezes}");
}
Console.WriteLine($"Frutas diferentes: {contagem.Count}");

Resumo

  • Um Dictionary<TKey, TValue> liga cada chave (única) a um valor e acha qualquer chave muito rápido.
  • d[k] = v cria ou troca; d.Add(k, v) só cria e lança ArgumentException se a chave já existe.
  • Ler d[k] com uma chave que não existe lança KeyNotFoundException. Quando a chave pode faltar, use TryGetValue ou GetValueOrDefault.
  • foreach (var (chave, valor) in d) percorre os pares; Keys e Values dão só as chaves ou só os valores. Console.WriteLine(d) mostra só o nome do tipo.
  • A ordem de um Dictionary não é garantida (uma remoção já a muda). Para ordem de chave, use SortedDictionary ou ordene antes de mostrar.
  • Acrescentar chaves dentro do foreach do próprio dicionário dá InvalidOperationException. Anote numa lista e mude depois do laço.
