C# LINQ

LINQ ("Language Integrated Query", consulta integrada à linguagem) são os métodos que fazem perguntas a qualquer coleção: "quais custam menos de R$ 10?", "qual o total?", "agrupe por categoria". Esta página lista todos os operadores que você vai usar, por grupo, com exemplo e resultado. Para aprender com calma, comece por O que é LINQ; para ver tudo em uso num programa, o projeto Estoque da Lojinha.

Os resultados vêm do programa abaixo, rodado no dotnet 10.0.112 da máquina da Ana (pasta ~/cs/linq, cultura pt-BR) e no editor do guia, que deram a mesma saída. O LINQ está em System.Linq, que o C# já traz sem using.

O programa de exemplo

Os exemplos usam dois conjuntos: o array n = [5, 3, 8, 1, 9, 2, 8] e uma lista de produtos da lojinha da Ana. A função J só junta o resultado numa linha, com espaços. Cada linha da saída começa com o número que aparece na coluna "Linha" das tabelas:

[

    new("Papel A4", "Papelaria", 4, 27.50m),

static string J<T>(IEnumerable<T> s) => string.Join(" ", s);

Console.WriteLine("-- perguntar");
Console.WriteLine($"13 {n.Any()} {n.Any(x => x > 8)} {n.All(x => x > 0)} {n.Contains(8)} {new int[0].Any()} {n.SequenceEqual([5, 3, 8, 1, 9, 2, 8])}");

Console.WriteLine("-- agregar");

Console.WriteLine($"15 {estoque.Sum(p => p.Qtd * p.Preco):C} {estoque.Average(p => p.Preco):C} {estoque.Max(p => p.Preco):C} {estoque.MaxBy(p => p.Preco)!.Nome} {estoque.MinBy(p => p.Qtd)!.Nome}");

Console.WriteLine("-- agrupar");

{
    Console.WriteLine($"17 {g.Key}: produtos {g.Count()}, unidades {g.Sum(p => p.Qtd)}");
}
Console.WriteLine($"18 {J(estoque.CountBy(p => p.Categoria).Select(kv => $"{kv.Key}={kv.Value}"))}");

Console.WriteLine("-- conjuntos e junções");
int[] a = [1, 2, 3, 4], b = [3, 4, 5];
Console.WriteLine($"20 {J(a.Concat(b))} | {J(a.Union(b))} | {J(a.Intersect(b))} | {J(a.Except(b))}");
Console.WriteLine($"21 {J(a.Zip(b, (x, y) => x + y))} | {J(a.Append(9))} | {J(a.Prepend(0))}");
List<(string Categoria, string Empresa)> fornecedores = [("Papelaria", "Distribuidora Sol"), ("Escrita", "Canetas Brasil")];
var juntos = estoque.Join(fornecedores, p => p.Categoria, f => f.Categoria, (p, f) => $"{p.Nome}<-{f.Empresa}");

Console.WriteLine($"23 {string.Join(", ", todos)}");
Console.WriteLine($"24 {J(n.Index().Where(t => t.Item == 8).Select(t => t.Index))}");

Console.WriteLine("-- converter e gerar");

Console.WriteLine($"25 {precos["Mochila"]:C} {n.ToHashSet().Count} {n.ToList().Count} {n.ToArray().Length}");
Console.WriteLine($"26 {J(Enumerable.Range(1, 5))} | {J(Enumerable.Repeat("ha", 3))} | {Enumerable.Empty<int>().Count()}");

Quase todos os operadores recebem uma lambda: x => x > 4 lê-se "dado x, diga se x é maior que 4". E quase todos devolvem uma sequência (IEnumerable<T>), por isso dá para encadear: .Where(…).OrderBy(…).Select(…).

Sintaxe de consulta

O LINQ tem uma segunda forma de escrever, parecida com SQL. O compilador transforma uma na outra: o programa é o mesmo.

// consulta.cs — a mesma pergunta nas duas sintaxes
int[] notas = [7, 4, 9, 5, 10, 6];

var metodos = notas.Where(n => n >= 6).OrderByDescending(n => n).Select(n => $"nota {n}");

var consulta = from n in notas
               where n >= 6
               orderby n descending
               select $"nota {n}";

Console.WriteLine(string.Join(", ", metodos));
Console.WriteLine(string.Join(", ", consulta));

$ dotnet run consulta.cs
nota 10, nota 9, nota 7, nota 6
nota 10, nota 9, nota 7, nota 6

O guia usa a forma com métodos: ela é a mais comum e tem todos os operadores (Take, Count, MaxBy… não existem na sintaxe de consulta). Aula: O que é LINQ.

Execução adiada

Uma consulta como notas.Where(…) não calcula nada na hora: ela guarda a "receita", e a receita roda a cada vez que alguém percorre o resultado (com foreach, Count(), ToList()…).

// adiada.cs — a consulta roda quando é percorrida
List<int> notas = [7, 4, 9];
var aprovados = notas.Where(n => n >= 6);
var foto = notas.Where(n => n >= 6).ToList();
notas.Add(10);
Console.WriteLine($"consulta: {aprovados.Count()}  |  ToList: {foto.Count}");

$ dotnet run adiada.cs
consulta: 3  |  ToList: 2

Resumo

  • Filtrar: Where. Transformar: Select, SelectMany. Ordenar: OrderBy + ThenBy. Pedaços: Take, Skip, Chunk.
  • Um item: First/FirstOrDefault, Single, Last. Sim ou não: Any, All, Contains.
  • Contas: Count, Sum, Average, Min, Max, MinBy/MaxBy, Aggregate.
  • Grupos: GroupBy (g.Key), CountBy e AggregateBy (.NET 9). Junções: Join e, no .NET 10, LeftJoin/RightJoin.
  • As consultas são adiadas: rodam quando percorridas. ToList() guarda o resultado do momento.
  • First, Single, Average e Max numa sequência vazia lançam InvalidOperationException.
