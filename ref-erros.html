C# Erros do Compilador

Quando o código tem um erro, o compilador do C# não cria o programa e diz o que achou, com um código como CS0103. Esta página junta os erros e avisos que você mais vai ver, cada um com um código pequeno que o provoca, a mensagem real, o que ela quer dizer, como consertar e a aula que ensina o assunto. Todos foram provocados de verdade.

Como usar esta página
  • Procure pelo código (Ctrl+F e CS0103): ele é o mesmo em qualquer língua e em qualquer computador. Ou procure um pedaço da mensagem.
  • As mensagens estão como saem na máquina da Ana: dotnet 10.0.112 (C# 14) num Ubuntu em português, pasta ~/cs/erros, com dotnet run arquivo.cs. Os nomes entre aspas ("idad") mudam conforme o seu código; o resto é igual.
  • Em fóruns e no site da Microsoft, a mensagem aparece em inglês. Para os erros mais comuns, a página mostra também o texto em inglês.
  • O editor do guia usa o mesmo compilador (Roslyn) e mostra o mesmo código e a mesma mensagem.

Como ler uma mensagem do compilador

int idade = 29;
Console.WriteLine(idad);

$ dotnet run cs0103.cs
/home/ana/cs/erros/cs0103.cs(2,19): error CS0103: O nome "idad" não existe no contexto atual
/home/ana/cs/erros/cs0103.cs(1,5): warning CS0219: A variável "idade" é atribuída, mas seu valor nunca é usado

Ocorreu uma falha no build. Corrija os erros de build e execute novamente.
PedaçoO que quer dizer
/home/ana/cs/erros/cs0103.cso arquivo, com o caminho completo
(2,19)(linha, coluna): linha 2, coluna 19. Os editores de código pulam direto para lá.
erroro tipo: error (erro) impede o programa de ser criado; warning (aviso) deixa criar, mas aponta algo suspeito
CS0103o código do erro: "CS" de C Sharp e um número. É o que você procura
O nome "idad" não existe no contexto atuala mensagem
Ocorreu uma falha no build…o dotnet avisando que, por causa dos erros, não rodou nada
Três regras para qualquer erro
  1. Conserte o primeiro erro primeiro. Um erro de sintaxe costuma provocar outros em cascata, e eles somem junto.
  2. Olhe a linha apontada e a de cima. Um ; esquecido aparece como erro no fim da linha, mas às vezes o compilador só percebe na seguinte.
  3. Os avisos importam. O CS8602 (possível null) é o aviso de uma NullReferenceException que vai acontecer. Aula: Avisos do Compilador.

null e referências anuláveis (avisos)

Resumo

  • Uma mensagem tem arquivo, (linha,coluna), error ou warning, o código CSxxxx e o texto. Procure pelo código.
  • Conserte o primeiro erro primeiro e olhe também a linha de cima.
  • Os campeões: CS0103 (nome não existe), CS1002 (falta ;), CS0029/CS0266 (conversão), CS0165 (sem valor), CS0161 (falta return), CS1061 (membro não existe), CS0246 (tipo não achado ou falta using).
  • Avisos de null (CS8600, CS8602, CS8618) são exceções esperando para acontecer.
  • As mensagens do compilador saem em português; as exceções, ao rodar, em inglês (veja Exceções).
