C# Coleções

Uma coleção guarda vários valores juntos: a lista de compras, os preços da lojinha, a fila do banco. O .NET tem uma coleção para cada jeito de guardar. Esta página ajuda a escolher e depois lista os métodos de cada uma, com exemplo e resultado. Para aprender com calma, comece por Coleções e List<T>.

Os resultados vêm dos programas desta página (pasta ~/cs/col da Ana), rodados no dotnet 10.0.112 e no editor do guia, com a mesma saída. Todas estas coleções estão em System.Collections.Generic, que o C# já traz sem using.

Não conte com a ordem do Dictionary

Na saída acima, os pares saíram na ordem em que entraram, mas isso não é garantido: depois de remoções, um item novo pode ocupar o lugar de um que saiu. Para mostrar em ordem, use OrderBy (d.OrderBy(kv => kv.Key)) ou um SortedDictionary. Aula: Dictionary.

Experimente

Missão: a Ana quer contar quantas vezes cada fruta foi vendida, mas o programa cai com KeyNotFoundException na primeira fruta. Conserte a linha do contagem[fruta]++ para começar do zero quando a fruta é nova. A saída deve ter banana=3, maçã=2 e uva=1.

string[] vendas = ["banana", "maçã", "banana", "uva", "banana", "maçã"];
Dictionary<string, int> contagem = [];
foreach (string fruta in vendas)
{
    contagem[fruta]++;
}
foreach (var (fruta, vezes) in contagem)
{
    Console.WriteLine($"{fruta}={vezes}");
}

string[] vendas = ["banana", "maçã", "banana", "uva", "banana", "maçã"];
Dictionary<string, int> contagem = [];
foreach (string fruta in vendas)
{
    contagem[fruta] = contagem.GetValueOrDefault(fruta) + 1;
}
foreach (var (fruta, vezes) in contagem)
{
    Console.WriteLine($"{fruta}={vezes}");
}

Resumo

  • Padrão: List<T>. Por chave: Dictionary<K, V>. Sem repetidos: HashSet<T>. Ordem de chegada: Queue<T>. Último primeiro: Stack<T>. Tamanho fixo: array.
  • List tem Count; array e string têm Length.
  • No Dictionary, ler uma chave que não existe lança exceção: use TryGetValue ou GetValueOrDefault. Add com chave repetida também lança; d[k] = v troca.
  • Dequeue, Pop e Peek numa coleção vazia lançam InvalidOperationException: use as versões Try….
  • Não conte com a ordem de Dictionary e HashSet; para ordem, Sorted… ou OrderBy.
  • C# 12: [1, 2, 3], [] e [.. outra, 4] criam qualquer coleção.
