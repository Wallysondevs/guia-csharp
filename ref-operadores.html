C# Operadores

Operadores são os símbolos que fazem contas e comparações: +, ==, &&, ??… Esta página traz todos os operadores do C# 14 em tabelas: primeiro a precedência (quem é calculado primeiro numa expressão com vários), depois cada grupo, com exemplo e resultado. Para aprender com calma, comece por Operadores Aritméticos e Precedência.

Todos os resultados vêm dos programas desta página, rodados no dotnet 10.0.112 da máquina da Ana (pasta ~/cs/op, cultura pt-BR) e no editor do guia, que deram a mesma saída.

Tabela de precedência e associatividade

Numa expressão com vários operadores, os de cima da tabela são calculados antes dos de baixo, como a multiplicação antes da soma na escola. Na mesma linha, a associatividade decide: "esquerda → direita" quer dizer que 10 - 4 - 3 é (10 - 4) - 3; "direita → esquerda" quer dizer que a = b = 7 é a = (b = 7).

Na dúvida, parênteses

Ninguém decora as 17 linhas. Os parênteses não custam nada e deixam a intenção clara para quem lê: (a && b) || c é melhor que a && b || c, mesmo que os dois sejam iguais. Basta lembrar três coisas: * / % antes de + -; comparações antes de && e ||; e a atribuição por último. Aula: Precedência.

Armadilhas

Texto + número: a soma que vira emenda 
string nome = "Ana";
int idade = 29;
Console.WriteLine("Idade: " + idade + 1);
Console.WriteLine("Idade: " + (idade + 1));
Console.WriteLine(1 + 2 + " anos");
Console.WriteLine(nome + 1 + 2);

$ dotnet run e4.cs

O que aconteceu: + é calculado da esquerda para a direita. Em "Idade: " + idade + 1, primeiro vem "Idade: " + 29, que já é texto ("Idade: 29"); depois, texto + 1 emenda o 1. Em 1 + 2 + " anos", a conta 1 + 2 acontece antes de aparecer o texto.

Como consertar: parênteses na conta, (idade + 1), ou, melhor ainda, interpolação: $"Idade: {idade + 1}" (aula Interpolação).

Experimente

Missão: a Ana tirou 7 e 9 nas provas, mas o programa diz que a média é 11. Conserte a conta (sem mudar os números) para sair Média: 8.

int prova1 = 7;
int prova2 = 9;
int media = prova1 + prova2 / 2;
Console.WriteLine($"Média: {media}");

int prova1 = 7;
int prova2 = 9;
int media = (prova1 + prova2) / 2;
Console.WriteLine($"Média: {media}");

Experimente: tente prever cada resultado antes de rodar. Depois, tire e ponha parênteses e veja o que muda.

int a = 2, b = 3, c = 4;
Console.WriteLine(a + b * c);
Console.WriteLine((a + b) * c);
Console.WriteLine(a * b % c);
Console.WriteLine(a < b == b < c);
Console.WriteLine(a > b || b < c && c > 10);
Console.WriteLine("Total: " + a + b);
Console.WriteLine($"Total: {a + b}");
string? apelido = null;
Console.WriteLine(apelido ?? "sem apelido");

Resumo

  • São 17 níveis de precedência. O essencial: primários (x.y, f(), a[i], x++), unários (-x, !x, cast), * / %, + -, comparações, ==, &&, ||, ??, ?: e, por último, a atribuição e o =>.
  • Quase todos vão da esquerda para a direita; a atribuição, o ?? e o ?: vão da direita para a esquerda.
  • Divisão entre inteiros corta; % é o resto.
  • && e || param assim que sabem a resposta; & e | calculam os dois lados.
  • ?., ?? e ??= tratam o null; no C# 14, x?.y = valor também atribui.
  • Na dúvida, parênteses.
