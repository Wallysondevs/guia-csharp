Projeto Agenda de Contatos (JSON)

A Ana quer guardar os telefones dos clientes da lojinha num programa: cadastrar, listar, procurar, apagar e, o mais importante, não perder nada quando o programa fecha. É o primeiro projeto que lembra das coisas: a agenda fica num arquivo contatos.json, que o programa lê ao abrir e grava ao sair. No caminho, você monta um menu, trabalha com uma List de records e conhece o JSON, o formato que quase todo programa usa para guardar e trocar dados.

Você vai praticar
  • Um menu que repete com while e switch, chamando funções locais.
  • Uma List<Contato> que cresce com Add e diminui com Remove.
  • Buscar sem ligar para maiúsculas com StringComparison.OrdinalIgnoreCase (Métodos de String).
  • Guardar e ler a lista num arquivo com System.Text.Json, sem estragar os acentos.
  • Tratar um arquivo com defeito com try e catch.
  • Trabalhar num projeto com dois arquivos: Program.cs e Contato.cs.

Versão 1 · O menu, a lista e o record

Um contato tem nome e telefone: um record resolve. Os contatos ficam numa List<Contato>, uma lista que cresce conforme a Ana cadastra (um array teria tamanho fixo). E o programa é um menu: mostra as opções, lê a escolha, faz a tarefa e volta para o menu, até a Ana escolher 0.

List<Contato> contatos = new();

Console.WriteLine("=== Agenda da Ana ===");
while (true)
{
    Console.WriteLine();
    Console.WriteLine("1 Adicionar  2 Listar  0 Sair");
    Console.Write("Opção: ");
    string opcao = Console.ReadLine() ?? "0";
    if (opcao == "0")
    {
        break;
    }

    switch (opcao)
    {
        case "1":
            Adicionar();
            break;
        case "2":
            Listar();
            break;
        default:
            Console.WriteLine("Opção inválida.");
            break;
    }
}
Console.WriteLine("Até logo!");

void Adicionar()
{
    Console.Write("Nome: ");
    string nome = (Console.ReadLine() ?? "").Trim();
    Console.Write("Telefone: ");
    string telefone = (Console.ReadLine() ?? "").Trim();
    if (nome == "")
    {
        Console.WriteLine("O nome não pode ficar vazio.");
        return;
    }
    contatos.Add(new Contato(nome, telefone));
    Console.WriteLine($"{nome} adicionado.");
}

void Listar()
{
    if (contatos.Count == 0)
    {
        Console.WriteLine("Nenhum contato.");
        return;
    }
    foreach (Contato contato in contatos)
    {
        Console.WriteLine($"  {contato.Nome}: {contato.Telefone}");
    }
}

Uma lista vazia de contatos. O new() sem o nome do tipo funciona porque o tipo já está escrito à esquerda (target-typed new).
string opcao = Console.ReadLine() ?? "0";
A opção fica como texto, e o switch compara textos. Se a entrada acabar (null), vale como "0": sai do programa, em vez de repetir o menu para sempre.
case "1": Adicionar(); break;
Cada opção chama uma função local, declarada mais abaixo. Assim o menu fica curto e cada tarefa tem nome.
void Adicionar()
Uma função local: um método escrito direto no arquivo, depois das instruções. Sem static, ela enxerga as variáveis do programa principal, como contatos.
(Console.ReadLine() ?? "").Trim()
Lê o texto e tira os espaços das pontas: " Bruno " vira "Bruno".
if (nome == "") { …; return; }
Um contato sem nome não entra. O return sai só da função, e o programa volta ao menu.
contatos.Add(new Contato(nome, telefone));
Cria o contato e põe no fim da lista.
contatos.Count

Versão 2 · Buscar e remover

Com dezenas de contatos, a Ana precisa procurar ("quem era a Carla mesmo?") e apagar quem saiu da lista. O menu ganha as opções 3 e 4:

void Buscar()
{
    Console.Write("Buscar por: ");
    string termo = (Console.ReadLine() ?? "").Trim();
    int achados = 0;
    foreach (Contato contato in contatos)
    {
        if (contato.Nome.Contains(termo, StringComparison.OrdinalIgnoreCase))
        {
            Console.WriteLine($"  {contato.Nome}: {contato.Telefone}");
            achados++;
        }
    }
    if (achados == 0)
    {
        Console.WriteLine("Ninguém encontrado.");
    }
}

void Remover()
{
    Console.Write("Nome para remover: ");
    string nome = (Console.ReadLine() ?? "").Trim();
    Contato? alvo = null;
    foreach (Contato contato in contatos)
    {
        if (contato.Nome.Equals(nome, StringComparison.OrdinalIgnoreCase))
        {
            alvo = contato;
            break;
        }
    }
    if (alvo is null)
    {
        Console.WriteLine($"{nome} não está na agenda.");
        return;
    }
    contatos.Remove(alvo);
    Console.WriteLine($"{alvo.Nome} removido.");
}
contato.Nome.Contains(termo, StringComparison.OrdinalIgnoreCase)
"O nome contém o termo?", sem ligar para maiúsculas e minúsculas (ignore case): car acha Carla Souza. Sem o segundo argumento, Contains diferencia c de C.
int achados = 0;
Conta quantos combinaram, para dizer "Ninguém encontrado." quando for zero.
contato.Nome.Equals(nome, StringComparison.OrdinalIgnoreCase)
Para remover, o nome tem de ser igual (sem ligar para maiúsculas), não só conter: "Remover Ana" não deve apagar a "Ana Paula".
Contato? alvo = null;
O contato a remover. Começa como "nenhum" (o ? deixa guardar null, veja Referências Anuláveis).
break;
Achou: para de procurar.
contatos.Remove(alvo);

Remover dentro do foreach: Collection was modified

A primeira versão do Remover da Ana tirava o contato da lista ali mesmo, dentro do laço:

void Remover()
{
    Console.Write("Nome para remover: ");
    string nome = (Console.ReadLine() ?? "").Trim();
    foreach (Contato contato in contatos)
    {
        if (contato.Nome.Equals(nome, StringComparison.OrdinalIgnoreCase))
        {
            contatos.Remove(contato);
            Console.WriteLine($"{contato.Nome} removido.");
        }
    }
}

O que significa: "a coleção foi modificada; a enumeração não pode continuar". O Remove funcionou (apareceu "Bruno Lima removido."), mas o foreach da linha 87 estava no meio da lista: quando foi buscar o próximo contato, viu que a lista tinha mudado debaixo dele e lançou a exceção. O g__Remover|0_3 é o nome que o compilador dá à função local Remover, e a linha 27 é quem a chamou, no menu.

Como consertar: nunca mude uma lista enquanto um foreach passa por ela. Ache primeiro, remova depois, como na versão 2. Outra saída é contatos.RemoveAll(c => c.Nome.Equals(nome, StringComparison.OrdinalIgnoreCase)), que procura e remove de uma vez (é uma lambda).

Versão 3 · Salvar num arquivo JSON

Até aqui, tudo o que a Ana cadastra some quando o programa fecha: a lista mora na memória. Para guardar, o programa escreve a lista num arquivo. Em que formato? O JSON (JavaScript Object Notation) é texto puro, fácil de ler por pessoas e por programas, e o .NET já sabe transformar objetos em JSON e de volta (veja JSON). Transformar um objeto em texto se chama serializar.

using System.Text.Encodings.Web;
using System.Text.Json;

const string Arquivo = "contatos.json";
JsonSerializerOptions opcoes = new JsonSerializerOptions
{
    WriteIndented = true,
    Encoder = JavaScriptEncoder.UnsafeRelaxedJsonEscaping
};

List<Contato> contatos = new();

Console.WriteLine("=== Agenda da Ana ===");
// … o menu continua igual …
Salvar();
Console.WriteLine($"Agenda salva em {Arquivo}. Até logo!");

// … Adicionar, Listar, Buscar e Remover continuam iguais …

void Salvar()
{
    string json = JsonSerializer.Serialize(contatos, opcoes);
    File.WriteAllText(Arquivo, json);
}
using System.Text.Json;
Traz o JsonSerializer e o JsonSerializerOptions. Esse namespace não vem incluído sozinho.
using System.Text.Encodings.Web;
Traz o JavaScriptEncoder, para os acentos (veja o cenário).
const string Arquivo = "contatos.json";
O nome do arquivo, num lugar só. Sem pasta no nome, ele fica na pasta em que o programa roda: ~/projetos/Agenda.
WriteIndented = true
"Escrever com recuo": um campo por linha, fácil de ler. Sem isso, sai tudo numa linha.
JsonSerializer.Serialize(contatos, opcoes)
Transforma a lista inteira num texto JSON: [ … ] é a lista, cada { … } é um contato, com os nomes das propriedades entre aspas.
File.WriteAllText(Arquivo, json);
Cria o arquivo (ou troca o conteúdo, se já existir) com esse texto (Arquivos).

Resumo

  • Um menu é um while (true) que mostra as opções, lê a escolha e chama uma função para cada uma; ?? "0" faz o fim da entrada valer como "sair".
  • Funções locais sem static enxergam as variáveis do programa principal, como a lista.
  • Contains e Equals com StringComparison.OrdinalIgnoreCase comparam sem ligar para maiúsculas.
  • Nunca mude uma lista dentro de um foreach sobre ela: ache primeiro, remova depois (ou use RemoveAll).
  • JsonSerializer.Serialize + File.WriteAllText salvam; File.ReadAllText + Deserialize carregam. WriteIndented e UnsafeRelaxedJsonEscaping deixam o arquivo legível.
  • Confira se o arquivo existe e trate JsonException: um arquivo com defeito não pode derrubar o programa.
