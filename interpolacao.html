C# Interpolação

Até agora, para montar uma frase com variáveis, você colou pedaços com +: nome + " tem " + idade + " anos". Funciona, mas é fácil esquecer um espaço, e as aspas e os + se acumulam. O C# tem um jeito muito mais limpo: a interpolação. Você escreve a frase inteira e marca, entre chaves, onde entram os valores: $"{nome} tem {idade} anos". É a forma que você vai encontrar em quase todo código C# moderno. Nesta aula você vai ver como ela funciona, o que pode ir dentro das chaves e os erros mais comuns.

Você vai aprender
  • Montar textos com $"…{variavel}…" e por que isso é melhor que o +.
  • Colocar contas, métodos e comparações dentro das chaves.
  • Por que o operador ? : precisa de parênteses dentro das chaves.
  • Uma prévia da formatação ({preco:C}, {nome,-10}) e como escrever chaves de verdade ({{ }}).
  • As outras formas (+, string.Format) e os erros reais do compilador.

Todos os programas desta aula foram rodados com o .NET 10 na máquina fictícia da Ana (usuária ana, computador notebook, sistema em português do Brasil), na pasta ~/cs, com dotnet run arquivo.cs.

A ideia: um formulário com lacunas

Pense numa ficha de inscrição impressa: "Eu, ________, de ____ anos, moro em ________." O texto está pronto; só faltam as lacunas. Você preenche cada uma com a informação certa.

A interpolação é essa ficha. O $ antes das aspas avisa: "este texto tem lacunas". Cada lacuna é um par de chaves { }, e dentro dele vai o que deve ser escrito ali. A palavra "interpolar" quer dizer exatamente isso: "colocar no meio".

1. A primeira interpolação

string nome = "Ana";
int idade = 29;
Console.WriteLine($"Olá, {nome}!");
Console.WriteLine($"{nome} tem {idade} anos.");
Console.WriteLine(nome + " tem " + idade + " anos.");

$ dotnet run ola.cs
Olá, Ana!
Ana tem 29 anos.
Ana tem 29 anos.     « o mesmo resultado, com +
$"…"
O cifrão colado nas aspas transforma o texto numa string interpolada. Sem o $, as chaves seriam só caracteres comuns.
{nome}
Uma lacuna. Na hora de rodar, o C# troca {nome} pelo valor da variável: Ana.
{idade}
Números também entram: o C# converte para texto sozinho. Não precisa de +, nem de ToString().
linha 5
A mesma frase com +: repare quantas aspas e espaços você precisa controlar. Na interpolação, os espaços ficam visíveis dentro do texto, onde você espera.

O resultado é uma string normal, que pode ser guardada numa variável: string saudacao = $"Bom dia, {nome}!";.

2. Dentro das chaves vai qualquer expressão

Uma lacuna não precisa ser só uma variável. Pode ser qualquer expressão, qualquer coisa que produza um valor: uma conta, um método, uma comparação.

string nome = "Ana";
int idade = 29;
decimal preco = 12.5m;
int quantidade = 3;
Console.WriteLine($"Ano que vem, {nome} terá {idade + 1} anos.");
Console.WriteLine($"Total: {preco * quantidade}");
Console.WriteLine($"Em maiúsculas: {nome.ToUpper()}");
Console.WriteLine($"O nome tem {nome.Length} letras.");
Console.WriteLine($"Maior de idade? {idade >= 18}");
Console.WriteLine($"Média: {(7 + 8) / 2.0}");

$ dotnet run expr.cs
Ano que vem, Ana terá 30 anos.     « a conta foi feita antes de entrar no texto
Total: 37,5                        « vírgula: a cultura da máquina é pt-BR
Em maiúsculas: ANA
O nome tem 3 letras.
Maior de idade? True
Média: 7,5

Repare na linha do idade >= 18: na aula Operadores de Comparação, com +, essa comparação precisava de parênteses ("…" + (idade >= 18)), senão dava erro. Dentro das chaves, ela é calculada sozinha, e o problema some. O mesmo vale para a conta: {idade + 1} nunca vira "291", como aconteceria com "…" + idade + 1 (aula Precedência).

Os números aparecem com vírgula decimal (37,5) porque a interpolação usa a cultura do computador, que na máquina da Ana é pt-BR. Num computador em inglês, sairia 37.5 (aula Cultura).

Mantenha as chaves simples

Dá para pôr muita coisa dentro das chaves, mas uma conta grande no meio da frase fica difícil de ler. Se a expressão passou de uma conta simples, calcule antes numa variável com nome: decimal total = preco * quantidade; e depois $"Total: {total}".

O ? : precisa de parênteses

O operador ternário (condição ? sim : não, aula Operador Ternário) escolhe entre dois valores. Dentro das chaves, ele vai entre parênteses:

int idade = 15;
Console.WriteLine($"Situação: {(idade >= 18 ? "adulto" : "menor")}");

$ dotnet run ternario.cs
Situação: menor

O motivo: dentro das chaves, o : tem outro trabalho, que é começar a formatação (próxima seção). Sem os parênteses, o C# acha que "menor" é um formato e se perde. O erro está em Quando dá errado. Repare também que dá para usar aspas ("adulto") dentro das chaves.

3. Formatar e alinhar dentro das chaves

Depois do valor, dentro das mesmas chaves, você pode dizer como ele deve aparecer: com : vem o formato, e com , vem a largura.

decimal preco = 1234.5m;
double media = 7.456;
Console.WriteLine($"Preço: {preco:C}");
Console.WriteLine($"Média: {media:F1}");
Console.WriteLine($"[{"Ana",-8}] [{"Bia",8}]");
Console.WriteLine($"{3.5}");

$ dotnet run fmt.cs
Preço: R$ 1.234,50       « C = moeda (currency), pelas regras do Brasil
Média: 7,5               « F1 = uma casa depois da vírgula (arredondada)
[Ana     ] [     Bia]    « ,-8 = 8 de largura, encostado à esquerda; ,8 = à direita
3,5
{preco:C}
O C (currency, "moeda") mostra o valor como dinheiro, no padrão do país do computador: R$, ponto nos milhares, vírgula e duas casas.
{media:F1}
"Ponto fixo com 1 casa decimal": 7,456 vira 7,5 (arredondado).
{"Ana",-8}
Reserva 8 posições para o valor. Negativo: o texto encosta à esquerda e os espaços vão depois. Positivo: encosta à direita.

Esses formatos são todo um assunto, com uma aula só para eles: Formatar Números (N2, C, P). Aqui basta saber que eles moram dentro das chaves, depois do : e da ,.

4. Como escrever uma chave de verdade

E se você quiser que apareça uma chave no texto, como em {nome}? Numa string interpolada, dobre a chave: {{ vira { e }} vira }.

string nome = "Ana";
Console.WriteLine($"{{nome}} vale {nome}");
Console.WriteLine($"Conjunto: {{ {1}, {2}, {3} }}");

$ dotnet run chaves.cs
{nome} vale Ana          « {{nome}} virou o texto {nome}; {nome} virou Ana
Conjunto: { 1, 2, 3 }

Numa string comum (sem $), as chaves não têm nada de especial e não precisam ser dobradas. Para textos com muitas chaves, como um JSON, existe a string bruta interpolada $"""…""" C# 11, explicada em Escapes e Strings Literais.

Formas diferentes de montar o mesmo texto

O string.Format tem uma armadilha: se o texto pede {1} e você passa um valor só, o erro só aparece quando o programa roda (veja abaixo). Na interpolação, o valor está escrito dentro da lacuna, e esse erro não existe.

Quando dá errado

Apareceu {nome} na tela, com as chaves

O que significa: faltou o $. Sem ele, {nome} é só texto. O único sinal do compilador é o aviso CS0219: "a variável nome nunca é usada", porque para ele, de fato, não foi. Se a variável fosse usada em outra linha, nem esse aviso apareceria.

Como consertar: $"Olá, {nome}!", com o $ colado nas aspas.

Resumo

  • Interpolação: $"…{valor}…". O $ colado nas aspas; cada { } é uma lacuna.
  • Dentro das chaves vai qualquer expressão: {idade + 1}, {nome.ToUpper()}, {idade >= 18}.
  • O ternário vai entre parênteses: {(cond ? a : b)}; senão, CS8361.
  • {x:C} formata, {x,10} alinha (aula Formatar Números). Os números seguem a cultura (37,5).
  • Chave de verdade: {{ e }}.
  • Sem o $, as chaves aparecem na tela. Chave sem fechar: CS8076; chave sobrando: CS8086.
  • Prefira a interpolação ao + com vários pedaços e ao string.Format.
